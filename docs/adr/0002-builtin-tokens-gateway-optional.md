# ADR-0002: Встроенные bearer-токены; agentgateway — опция, не требование

- **Статус:** accepted (рекомендация рана 2026-08-29; режимы не исключают
  друг друга, откат дешёв)
- **Контекст:** сегодня робот ходит на мост через agentgateway владельца
  (loopback-бинд, auth у гейтвея). У внешнего пользователя P-02 гейтвея нет;
  требование «разверни ещё один сервис» убивает онбординг.
- **Решение:** мост получает собственную auth: статический bearer на
  клиента (robot/phone/panel), выдача через пейринг, отзыв в настройках.
  MCP-auth — внешняя ASGI-middleware вокруг Mount (SDK-совместимо,
  research-notes §A). Режим gateway (loopback за agentgateway) сохраняется
  конфигом — машина оператора продолжает работать как сейчас.
- **Последствия:** (+) онбординг P-02 — «два конца обменялись токеном»;
  (+) DNS-rebinding-защита возвращается с явными allowed_hosts вместо
  выключателя M4. (−) мост начинает владеть секретами → инварианты §11
  (0600, не логировать, ротация); (−) два режима = две строки в матрице
  тестов.
