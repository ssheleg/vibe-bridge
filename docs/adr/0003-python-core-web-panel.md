# ADR-0003: Python-ядро + веб-панель; трей per-OS; без переписывания

- **Статус:** accepted (оператор, грилл G3, 2026-08-29)
- **Контекст:** кроссплатформенность (macOS/Windows/Linux + телефон) при
  живом Python-ядре M1–M4 и wire-парности `mcp==1.26.0` с Hermes.
  Альтернативы: Tauri/Rust (переписывание ядра, потеря паритета
  python-SDK), Electron (150+ МБ и второй процесс).
- **Решение:** ядро остаётся Python; UI — локальная веб-панель из того же
  процесса (Starlette + SSE + PWA), один интерфейс на десктоп и телефон;
  трей — абстракция над rumps (macOS) и pystray (Win/Linux); main thread
  принадлежит трею, сервер — в worker-thread (research-notes §D).
- **Последствия:** (+) весь код M1–M4 переиспользуется; один UI вместо
  трёх; телефон бесплатно. (−) «нативность» ограничена треем и диалогами;
  консент-диалог на не-macOS платформах v1 может жить в панели/уведомлении
  (уточняется на build); упаковка Python-приложений per-OS — отдельная
  веха (спека §9).
