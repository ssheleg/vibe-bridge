# ADR-0004: Телефон — PWA по tailnet + Web Push; Telegram — только fallback

- **Статус:** accepted (оператор, грилл G2, 2026-08-29)
- **Контекст:** консент-запрос без ответа = отказ через 60 с; вне
  компьютера владелец терял запросы. Альтернативы: свой Telegram-канал
  моста (тянет зависимость в новый продукт), нативные приложения (две
  кодовые базы + сторы).
- **Решение:** та же веб-панель как PWA через `tailscale serve`
  (LE-сертификат tailnet-имени); консент-пуши — стандартный VAPID Web Push:
  исходящие POST, входящая достижимость не нужна; iOS — Home-Screen PWA
  (16.4+), Android — кнопки Allow/Deny прямо на уведомлении
  (research-notes §C). Пуш расширяет окно внимания, не меняя дефолт
  «тишина = отказ». Telegram-канал моста — опциональный fallback второй
  очереди (long-poll, inline-кнопки), не в v1.
- **Последствия:** (+) ноль своей инфраструктуры, приватность (анти-облако
  vision §6); (+) один UI. (−) требуются MagicDNS+HTTPS в тейлнете
  (визард проверяет и объясняет); (−) имя устройства попадает в CT-лог —
  задокументировать; (−) iOS без кнопок на пуше — тап обязателен.
