# ADR-0005: Имя продукта — vibe-bridge

- **Статус:** accepted (оператор, грилл G4, 2026-08-29)
- **Контекст:** «mac-bridge» перестаёт быть правдой на Windows/Linux; спека
  и UX пишутся под имя. Альтернативы: robot-bridge (generic, хуже ищется),
  оставить mac-bridge (ложь на двух ОС из трёх).
- **Решение:** продукт называется **vibe-bridge** (семья robot-vibecoder
  читается, платформа в имя не зашита). Репозиторий, пакет и модуль
  (`macbridge` → `vibebridge`) переименовываются на build-этапе — CO-1.
- **Последствия:** (+) имя переживает кроссплатформенность и рост семьи;
  (−) одна волна переименований (репо GitHub, LaunchAgent label, пути
  логов) — делается одним коммитом build-рана с migration-заметкой.
