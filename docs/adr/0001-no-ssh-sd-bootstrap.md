# ADR-0001: Бутстрап Raspberry Pi — SD-образ, без SSH

- **Статус:** accepted (оператор, грилл G1, 2026-08-29)
- **Контекст:** визарду нужно поставить стек робота на свежую Pi. Канон
  флота робота — «никакого SSH, обновления только через GitHub»
  (fleet-update-policy); формулировка задачи («скачать репозиторий,
  поставить, запустить») звучала как SSH-установка — конфликт решён вслух.
- **Решение:** визард готовит SD-карту: стоковый Raspberry Pi OS + FAT-only
  кастомизация (`firstrun.sh`+`cmdline.txt` на Bookworm, cloud-init на
  Trixie); робот самоустанавливается на первом буте и дальше живёт своим
  GitHub-таймером. SSH не используется ни на одном шаге
  (механика — research-notes.md §B).
- **Последствия:** (+) канон флота не нарушен; Windows-совместимость (FAT
  пишется отовсюду); ошибка установки видна визарду только по невыходу
  робота на связь → обязателен таймаут-порог с диагностикой (SCN-016).
  (−) нет прямого канала «посмотреть логи установки» — принято; диагностика
  идёт через физические проверки и, позже, статус-маяк робота.
