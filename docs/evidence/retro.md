# Retro — vibe-bridge

## Standing instructions (bind every run; max 10)

1. **Wire-парность:** `mcp` SDK бампается только вместе с `HERMES_VERSION`
   робота (README «Wire parity»); проверять на каждом build-ране.
2. **Fleet-канон робота — no SSH:** любой дизайн-ход, требующий SSH к Pi,
   сверять с fleet-update-policy робота и решать вслух у оператора
   (решено G1 2026-08-29: SD-бутстрап без SSH).
3. **Упакованное приложение — отдельная среда, а не деталь сборки.** Пути,
   версии, системные фреймворки и TLS ведут себя внутри `.app` иначе, чем в
   `uv run`. Всё, что их касается, проверять на собранном приложении (сегмент
   3: четыре бага, невидимых в репозитории).
4. **Проверку и необратимое действие не связывать одной командой.** Прогон
   тестов через `&&` перед `git push` — это гейт, вывод которого некому
   прочитать (сегмент 3: красный коммит в origin).

### 2026-08-31 · build-8 · borderless окно не принимает клавиатуру
- **Симптом:** в поле ввода виджета нельзя было напечатать ни символа.
- **Причина:** `NSWindowStyleMaskBorderless` заставляет
  `canBecomeKeyWindow` возвращать NO — клавиатура до окна не доходит в
  принципе. Выбор borderless был сделан ради вида, а не ради поведения.
- **Фикс (grade: code):** titled + `FullSizeContentView` со скрытым
  заголовком (выглядит так же) и `becomesKeyOnlyIfNeeded`, чтобы фокус
  забирался только контролом. Заодно снят `movableByWindowBackground`: он
  съедал mouse-down и клик не доходил до страницы.
- **Чек на будущее:** выбирая стиль окна, проверять не только вид, но и
  `canBecomeKeyWindow` — иначе поверхность выглядит правильно и не работает.

### 2026-08-31 · build-7 · CSS из другого рантайма, принятая за рабочую
- **Симптом:** питомца нельзя было сдвинуть с места.

  `WKWebView` его нет, свойство просто игнорируется, и никакой ошибки при
  этом не возникает: CSS молча пропускает то, чего не знает.
- **Фикс (grade: code):** страница шлёт дельту через WKScriptMessageHandler,
  окно двигает себя; тест проверяет, что свойства нет в правиле.
- **Чек на будущее:** CSS-свойство с префиксом рантайма (`-webkit-app-region`,
  `-moz-*`) проверять на целевом движке, а не считать поддержанным по виду.
  Молчаливое игнорирование — худший вид отказа: он не оставляет следов.
