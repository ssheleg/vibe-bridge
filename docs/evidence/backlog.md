# Аудит 2026-09-01 — находки и план

Аудит запускался семью субагентами, каждому свой угол. **Пять из семи упали на
внешнем ограничении** (`individual spend limit`), поэтому доказательную базу
имеют только три угла: юзабилити (агент), шов робот↔мост (агент) и
логика/границы безопасности (проверено мной вручную). **НЕ проаудированы:**
архитектура кода, визуальный слой, соответствие сценариям/JTBD, качество
тестов. Это не «там всё хорошо» — это «там не смотрели».
